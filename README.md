# Data Science Projects

I’m a mechanical engineer with experience in 1D system simulation using Simcenter Amesim and a passion for simulation and digital twins. I’m exploring how data-driven methods can complement traditional physics-based models. This repository documents that journey through hands-on projects focused on building useful models.

The portofolio consists of data science and machine-learning projects, primarily developed in Python notebooks. Projects are grouped into `Beginner`, `Intermediate` and `Advanced` folders according to their complexity covering topics from Regression and Classification to Artifical Neural Networks battery health and electric-vehicle charging.

## Getting started

The projects are Jupyter notebooks. Open a notebook on GitHub to read it, or run it locally with Jupyter. Check the notebook for its data source, setup steps, and any project-specific requirements.

Projects marked with a branch name are currently on that branch and are not yet part of the `main` branch. Their links open the corresponding branch version on GitHub.
