# Data Science Projects

A portfolio of data science and machine-learning projects, primarily developed in Python notebooks. Projects are grouped into `Beginner` and `Intermediate` folders and cover topics from regression and classification to battery health and electric-vehicle charging.

## Projects

| Project | Overview | Notebook | Availability |
|---|---|---|---|
| House Price Regression | Explore a Kaggle house-price regression problem. | [Open notebook](Beginner/HousePriceRegression/HousePriceRegression.ipynb) | On `main` |
| Telco Customer Churn | Prepare data, explore churn patterns, engineer features, and build models for a telecommunications customer-churn problem. | [Open notebook](Beginner/TelcoCustomerChurn/TelcoCustomerChurn.ipynb) | On `main` |
| Craigslist Used Car Price | Build a model to estimate used-car values from Craigslist vehicle listings. | [Open notebook](https://github.com/RobertMatei35/DataScienceProjects/blob/CraigslistUsedCares/Beginner/CraigslistUsedCars/CraigslistUsedCars.ipynb) | On `CraigslistUsedCares` |
| Residential EV Charging | Explore residential EV charging sessions, loads, idle capacity, and related weather and traffic data. | [Open notebook](https://github.com/RobertMatei35/DataScienceProjects/blob/EVCharging/Beginner/EVCharging/ResidentialEVCharging.ipynb) | On `EVCharging` |
| Battery Remaining Useful Life (RUL) Estimator | Use an artificial neural network to estimate battery remaining useful life with the NASA battery dataset. | [Open notebook](https://github.com/RobertMatei35/DataScienceProjects/blob/Battery_RUL_Estimator/Intermediate/Battery_RUL_Estimator/Battery_RUL_Estimator.ipynb) | On `Battery_RUL_Estimator` |
| Austin Grand Prix Winner Prediction | Use historical Formula 1 results to rank potential Austin Grand Prix winners; the scores are not confirmed win probabilities. | [Open notebook](https://github.com/RobertMatei35/DataScienceProjects/blob/F1_AustinGP_WinnerPrediction/Intermediate/Formula1/AustinGP_WinnerPredictor/Austin_GP_Winner_Predictor.ipynb) | On `F1_AustinGP_WinnerPrediction` |

## Getting started

The projects are Jupyter notebooks. Open a notebook on GitHub to read it, or run it locally with Jupyter. Check the notebook for its data source, setup steps, and any project-specific requirements.

Projects marked with a branch name are currently on that branch and are not yet part of the `main` branch. Their links open the corresponding branch version on GitHub.
